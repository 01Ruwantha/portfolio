Project Overview

As part of Group 17 from the Department of Computer Science, University of Ruhuna, under the supervision of Mrs. T.D.G. Geethika, we engineered InstaLearn — an enterprise-grade education management platform designed to automate and streamline operations in tuition centers.

Core Capabilities

✅ QR-Based Attendance Management: Instant camera and handheld barcode scanner check-ins that notify parents in real time.
✅ Role-Based Portals: Secure, tailored dashboards for administrators, teachers, students, and parents.
✅ Exam Question Pool & Automation: Centralized test generation, automatic grading, and marks distribution.
✅ Progress Tracking: Visual analytics representing attendance rates, test performance, and individual milestones.
✅ Payment Gateway Integration: Online fee payments with invoice generation and automated reminder alerts.

Technical Architecture

• Frontend: React.js, Redux State Management, Bootstrap 5, CSS3.
• Backend: Spring Boot RESTful API with JPA/Hibernate.
• Database: MySQL relational database schema with optimized indexing.
• Version Control & UI: Git, GitHub, and Figma prototyping.
