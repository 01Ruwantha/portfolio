Overview

A modern, user-friendly, and responsive calculator engineered with Flutter. Features split-screen tablet layout and local Hive NoSQL database storage for persistent calculation history.

Key Features

• Adaptive Layout: Mobile single-screen view and tablet dual-pane split view.
• Hive NoSQL Storage: High-performance instant calculation history persistence.
• 100% Offline: Requires zero internet access, ultra lightweight and fast.
